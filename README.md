## Data Connect (Cloud SQL PostgreSQL)

1.Install the Firebase Data Connect extension from the VS Code Marketplace.

2.Click the Sign in with Google button.

3.Click the Connect a Firebase project button.

4.Click the Run firebase init button.

5.Click the Start emulators button to run the Data Connect emulator with a local PGlite database.

use ```firebase dataconnect:sdk:generate``` for update ORM Queries, Mutation
